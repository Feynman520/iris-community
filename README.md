# IRIS Workspace — 협업 문서 (Community Documents)

> **English summary.** This repository holds the shared community documents for the public IRIS Workspace repositories listed below: how to contribute, how decisions are made, the contributor license agreement, the trademark policy, and the security policy. Each of those repositories carries a short `CONTRIBUTING.md` and `SECURITY.md` that point here.

IRIS Workspace의 공개 저장소들이 함께 쓰는 안내 문서를 모아 둔 곳입니다. 문서 원본은 여기 한 벌만 두고, 아래 저장소마다 이곳을 가리키는 짧은 안내(`CONTRIBUTING.md`·`SECURITY.md`)와 Issue·PR 양식을 둡니다.

| 문서 | 무엇을 알려 주나 |
|---|---|
| [CONTRIBUTING.md](CONTRIBUTING.md) | 의견을 내거나 코드를 보태는 방법, 저장소마다 받는 것 |
| [GOVERNANCE.md](GOVERNANCE.md) | 누가 무엇을 결정하는지, 역할과 권한 |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | 서로 지킬 행동 강령 |
| [SECURITY.md](SECURITY.md) | 보안 문제를 비공개로 알리는 방법 |
| [CLA.md](CLA.md) | 기여 동의서 (Contributor License Agreement) |
| [TRADEMARKS.md](TRADEMARKS.md) | IRIS Workspace 이름과 로고를 쓸 수 있는 범위 |

## 커뮤니티 판 소개 신청

IRIS Workspace를 고쳐 만든 자기 판을 공식 홈페이지의 커뮤니티 쪽에 소개하고 싶다면 [소개 신청 양식](https://github.com/Feynman520/iris-community/issues/new?template=community-listing.yml)을 써 주세요. 조건과 표기는 [TRADEMARKS.md](TRADEMARKS.md)의 「커뮤니티 판」 절에 있습니다. 소개는 검증이나 보증이 아니며, 올릴지는 관리자가 정합니다.

코드는 모두 MIT 라이선스입니다. 이름과 로고는 [TRADEMARKS.md](TRADEMARKS.md)를 따릅니다.

GitHub 계정이 없어도 의견을 보낼 수 있습니다: <https://iris-workspace.com/feedback>
